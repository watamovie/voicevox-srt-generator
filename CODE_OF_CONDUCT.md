# Code of Conduct

This project should be a practical and respectful space for users and
contributors.

## Expected behavior

- Be respectful and constructive.
- Assume contributors may be using different browsers, operating systems, and
  video-editing tools.
- Keep bug reports focused on reproducible behavior.
- Avoid sharing private audio, scripts, or personal data in public issues.

## Unacceptable behavior

- Harassment, insults, or discriminatory language.
- Publishing another person's private information.
- Posting exploit details or private user files publicly when a responsible
  security report would be more appropriate.

## Enforcement

The maintainer may edit, hide, or delete comments, issues, or pull requests that
violate this code of conduct. Repeated or severe violations may result in being
blocked from the project.
