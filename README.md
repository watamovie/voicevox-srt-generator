# voicevox-srt-generator

ブラウザ上で動作する小さな SRT 字幕ジェネレーターです。VOICEVOX などで書き出した連番の音声ファイル（`.wav`）とテキストファイル（`.txt`）のペアを読み込み、音声の長さに合わせて簡易的な字幕タイミングを生成します。

選択したファイルはブラウザ内で処理され、アプリケーションのサーバーへアップロードされません。

このリポジトリは VOICEVOX 公式プロジェクトではない、個人制作の非公式ツールです。
VOICEVOX 本体、エンジン、コア、音声ライブラリ、キャラクター素材は含んでいません。
現状提供の小ツールであり、継続的なサポートや動作保証はありません。

## 主な機能

- 同名の `.wav` と `.txt` をペアにして解析
- Web Audio API を用いた音声長の自動計測
- 手動調整（固定値の加算）と自動調整（目標合計時間に合わせる）の2モード
- フレームレートに合わせたタイムコード調整
- ミリ秒単位でのタイムスタンプ書式化と四捨五入誤差の抑制
- 生成した `.srt` ファイルをその場でダウンロード

## 対応しないこと

- 音声認識や文字起こし
- 翻訳
- `.vvproj` / `.aisp` などのプロジェクトファイル解析
- 字幕タイミングの完全保証

## 使い方

1. `index.html` をブラウザで開きます（Cloudflare Pages などにデプロイしても OK）。
2. 「フォルダを選択」または「ファイルを選択」から、`001.wav` + `001.txt` のように同名のペアが揃ったファイル群を読み込みます。
3. タイミング調整モードを選びます。
   - **手動調整**: 全字幕に同じ秒数を加算します（例: `0.02`）。
   - **自動調整**: 目標とする全体時間（秒）を指定し、均等に微調整します。
4. 「SRTを生成」ボタンを押すと解析が実行され、統計とログが表示されます。
5. 「SRTファイルをダウンロード」ボタンから `output.srt` を保存します。

> ⚠️ ブラウザのタブを閉じると選択したファイル情報は破棄されます。必要に応じて再度読み込んでください。

## 開発

このリポジトリはビルドステップを必要としない純粋な静的サイトです。

```bash
open index.html
```

ローカル HTTP サーバーで確認したい場合は、任意の静的サーバーを使ってください。

```bash
python3 -m http.server 8000
```

その後、`http://localhost:8000` を開きます。

## デプロイ

`index.html`、`styles.css`、`app.js`、`favicon.svg`、`terms.html` を任意の静的ホストに配置してください。ビルドコマンドや環境変数は不要です。

## 注意事項

- `.wav` と `.txt` は同じベース名で用意してください。
- 生成された `.srt` はローカルでダウンロードされます。リポジトリへコミットしないでください。
- ブラウザによってフォルダ選択やドラッグ＆ドロップの挙動が異なる場合があります。
- VOICEVOX で作成した音声を利用する場合は、[VOICEVOX ソフトウェア利用規約](https://voicevox.hiroshiba.jp/term/)および各音声ライブラリの利用規約に従ってください。
- VOICEVOX の利用時は、VOICEVOX を利用したことがわかるクレジット表記が必要です。
