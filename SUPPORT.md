# Support

This project is maintained as a small open-source utility.

## Before opening an issue

- Confirm that each `.wav` file has a matching `.txt` file with the same base name.
- Try the latest public version: https://srt-wavtxt-tool.pages.dev/
- Try a local static server if opening `index.html` directly behaves differently:

```bash
python3 -m http.server 8000
```

## What to include

- Browser and OS.
- File selection method: file picker, folder picker, or drag and drop.
- Number of `.wav` and `.txt` files.
- Frame-rate settings and timing adjustment mode.
- The error message or log shown by the app.

Do not upload private voice files or scripts to public issues.
